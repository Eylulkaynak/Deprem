# Story UI Font Family

- Lexend: https://github.com/google/fonts/tree/main/ofl/lexend

Lexend is distributed under the SIL Open Font License 1.1. The license text is
included beside the font files.

The UI uses one family so headings, buttons, objectives, and subtitles remain
consistent and readable on a vertical mobile screen. Static instances were
generated from the upstream variable font at weights 450, 600, and 750.
The illustrated game logo carries the playful display character; interface text
stays calm and legible. All selected font files include the Turkish glyphs used
by the game.
