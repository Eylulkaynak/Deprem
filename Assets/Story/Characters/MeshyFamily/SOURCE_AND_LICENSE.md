# Meshy Family Character Set

These character models were generated for the Deprem project from the approved
reference images in `ArtDirection/CharacterReferences`.

- Generator: Meshy
- Generation model: Meshy 5
- License selected during generation: CC BY 4.0
- Attribution: Model created with Meshy
- Generated roles: Deniz, Can, Anne, Baba, Komsu

## Rig status

- `Deniz/Extracted`: Meshy humanoid rig and walking animation.
- `Can/BlenderRigged/Can_Rigged.fbx`
- `Anne/BlenderRigged/Anne_Rigged.fbx`
- `Baba/BlenderRigged/Baba_Rigged.fbx`
- `Komsu/BlenderRigged/Komsu_Rigged.fbx`

The four Blender-rigged FBX files use the same 21-bone Unity-friendly naming
scheme, embedded PBR textures, a maximum of four bone influences per vertex,
and no unweighted vertices. Their optimized meshes are approximately 55,000
triangles each. Matching review renders are stored beside each FBX.

These are source/review assets outside Unity's `Assets` tree. Copy them into
the project only when scene character replacement and animation retargeting
are ready to begin.
